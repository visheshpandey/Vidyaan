# Changelog

## 0.3.0

- Renamed the product to GRANTLY
- Help page with a glossary of difficult terms and common questions
- Step checklist on each application with saved progress
- Richer Discover filters (level, provider, closing date) and pagination
- What-if simulator to see which scholarships a changed answer would unlock
- PWA: installable and works offline through a service worker
- Runtime data loading from `/data/scholarships.json` with validation, 10 minute cache and bundled fallback
- More scholarships in the dataset
- Documentation: user stories, personas, API, deployment, troubleshooting, code of conduct, issue and pull request templates, requirement IDs in test titles

## 0.2.0

- Dark mode and English or Hindi for the main screens
- Compare view for up to three scholarships
- Drag-and-drop board with keyboard support
- Optional daily browser reminders for upcoming deadlines
- Discover filters stored in the URL
- Landing page redesign with a real example card
- Stronger colour contrast in light mode, larger touch targets, confirmation before deleting a document

## 0.1.0

- Eligibility engine with Eligible, Needs information and Not eligible outcomes
- Onboarding, dashboard with derived metrics and next steps, Discover with search and filters
- Scholarship detail with plain-language eligibility breakdown
- Saved list, application tracker with status menu, notes and history
- Documents with expiry and readiness, deadlines calendar with .ics export
- Profile editing, JSON and CSV export, demo data and clear-all
- Accessibility tests for every page
