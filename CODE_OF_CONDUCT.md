# Code of Conduct

## Our pledge

We want GRANTLY to be a welcoming project for everyone, whatever their age, background, gender, ability, language or experience. Many of our users are students, so we hold ourselves to a high standard of kindness.

## Expected behaviour

- Be respectful and patient, especially with newcomers.
- Give and accept feedback on the work, not the person.
- Use plain language and explain jargon.
- Respect privacy. Never share a student's personal data.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Sexual language or unwelcome attention.
- Publishing others' private information.
- Anything that would be unwelcome in a professional setting.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that break this code, and may ban repeat offenders. Report concerns by opening a private security advisory on the GitHub repository or contacting the maintainers listed there. Reports are handled in confidence.
